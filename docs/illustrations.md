# イラスト指定書（設計論・設計の要素のページ）

設計会のサイトに載せるイラストの指定です。描いてくれる人（デザインを学ぶ学生のみなさん）向けに書いています。

- サイトでは、まだ描かれていないイラストの場所に、番号（例：`E3-01`）の入った「制作中」の枠が出ています。`npm run dev` で開いて、どこに入るかを見ながら描いてください
- 文章（何を伝えたいか）は決まっていますが、**構図や表現は自由に変えてかまいません**。「描くもの」はたたき台です。もっと伝わる案があれば、そちらを優先してください
- 迷ったら、各項目の「伝えたいこと」を優先してください

## 全体の決まりごと（全点共通）

サイト全体の雰囲気は「誠実で、読ませる」です。派手さより、落ち着きと正確さを大切にしています。テーマは「設計図」です。

| 項目 | 決まりごと                                                                                                                  |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 画風 | 線画が基本。製図や設計図を思わせる、まっすぐで落ち着いた線。手描きの味は残してよいが、ラフすぎないこと                      |
| 線   | 太さはほぼ一定（書き出したサイズで 2〜3px 程度）。主線は黒（`#16181d`）                                                     |
| 色   | 黒の線＋**差し色を 1〜2 色まで**。下の「使える色」から選ぶ。グラデーションや影は使わない（ベタ塗り・網点・ハッチングは OK） |
| 背景 | 白（`#ffffff`）か、ごく薄い灰色（`#f6f7f9`）。方眼（`#e6e9ef`、32px 間隔）を薄く敷くのは OK                                 |
| 人物 | 顔は簡略化してよい（目鼻なしも可）。性別・年齢・体格・服装などは偏らせない。特定の実在の人物に似せない                      |
| 文字 | イラストの中に文字を入れるのは最小限に。入れる場合は日本語で、手書きよりも読みやすい書体で                                  |
| 禁止 | 実在の企業や製品のロゴ・画面をそのまま描くこと。他人の作品（有名な風刺画や写真など）を写したり、なぞったりすること          |

## 納品のしかた

- **形式**：SVG が第一希望（拡大してもきれいなため）。難しければ PNG（下の「書き出しサイズ」の 2 倍の大きさで）
- **書き出しサイズ**：比率ごとに次のとおり

  | 比率 | 書き出しサイズ（1 倍） |
  | ---- | ---------------------- |
  | 21:9 | 1680 × 720 px          |
  | 16:9 | 1600 × 900 px          |

- **ファイル名**：番号そのまま（例：`E3-01.svg`）
- **置き場所**：`public/uploads/illustrations/`
- **サイトに反映する**：その番号のイラストを書いている YAML（下の「載る場所」）に `src: /uploads/illustrations/E3-01.svg` の 1 行を足すと、「制作中」の枠が絵に置き換わります
- スマホでは横幅 340px くらいまで縮みます。**縮めても何の絵かわかるか**を確認してください（細かすぎる描き込みは避ける）

### ES-01

**机を囲んで議論する**｜トップ・設計論 §01 の冒頭｜21:9

- **伝えたいこと**：設計は「つくる前」に、何人もの視点で一つのものを考え抜く営みである。サイト全体の顔になる一枚
- **描くもの**：大きな机を真上から見た構図。机の上に、スケッチ、付箋、寸法の入った図面、ノートパソコン、定規、模型の部品などが広がり、4〜5 人が囲んでいる（頭と腕、手元だけが見える程度でよい）。何人かは図面を指さしたり、付箋を貼ったりしている
- **色**：差し色にオレンジ（付箋・発案）と青（図面の線）
- **注意**：机の上の「まだ形になっていないもの」が主役。人物は脇役
- **代替テキスト（alt）**：大きな机を数人が囲み、スケッチ、付箋、図面、ノートパソコンを広げて議論している様子を真上から見た絵

### ES-02

**一枚の設計図に集まる手**｜トップ・設計論 §09（最後の章）｜21:9

- **伝えたいこと**：設計は総合であり、一人ではなく、専門の違う人が持ち寄ってするもの。設計論の締めくくり
- **描くもの**：一枚の大きな設計図（何の図面かは特定しない、抽象的な線と寸法線）の上に、四方から手が伸びている。定規を当てる手、鉛筆で線を引く手、付箋を貼る手、タブレットを指す手。それぞれの手元から、違う色の線が図面に加わっている
- **色**：黒の図面に、オレンジ・緑・青の線が一本ずつ加わる（設計会の 3 つの役割の色）
- **注意**：手の肌の色や袖の服装に多様性を持たせる
- **代替テキスト（alt）**：一枚の大きな設計図の上に、定規を持つ手、鉛筆を持つ手、付箋を貼る手、タブレットを指す手が集まっている絵

### E1-01

**伝わるうちに形を変える願い**｜要求定義のページ上部｜16:9

- **伝えたいこと**：人の願いは、言葉で人から人へ伝わるうちに、少しずつ違うものに変わってしまう。だから「確かめられる形」に書く必要がある
- **描くもの**：左から右へ、依頼者 → 聞き手 → 設計者 → 製作者 と人が並び、それぞれの頭の上の吹き出しに「ほしいもの」の絵が描かれている。たとえば最初は「雨の日も濡れずに自転車で通学したい」という願い（屋根の付いた自転車）だったものが、伝わるうちに傘を固定した自転車、レインコート…と少しずつ形を変え、最後はまったく別のものになっている（何に変わるかは自由。ユーモアは歓迎）
- **注意**：よく知られた「ブランコの風刺画（顧客が本当に必要だったもの）」に似せないこと。題材も構図もオリジナルにする
- **代替テキスト（alt）**：依頼者の吹き出しの中の「ほしいもの」が、聞き手、設計者、製作者へと伝わるたびに少しずつ違う形に変わっていく様子を一枚に描いた絵

### E1-02

**自転車で見る狩野モデル**｜要求定義・設計での使い方（狩野モデルの図のあと）｜16:9

- **伝えたいこと**：一つの製品の中に、性格の違う要求が同居している
- **描くもの**：一台の自転車を中央に描き、三つの部分から吹き出しを出す。ブレーキ →「ちゃんと止まる」（当たり前品質）、フレーム →「軽い」（一元的品質）、ライト →「暗くなると自動で点く」（魅力的品質）
- **色**：吹き出しを品質ごとに色分け。当たり前＝緑、一元的＝青、魅力的＝オレンジ（サイトの図と同じ対応）
- **代替テキスト（alt）**：一台の自転車を中心に、「ブレーキが効く」（当たり前）、「軽い」（一元的）、「ライトが自動で点く」（魅力的）という三つの要求が、色分けされた吹き出しで示されている絵

### E2-01

**壁一面のカードと KJ 法**｜発想のページ上部｜16:9

- **伝えたいこと**：ばらばらの事実から、まだ名前のない構造を見つけ出す
- **描くもの**：壁や大きなボードにたくさんのカード（付箋）が貼られ、似たものが寄せられて線で囲まれ、小さな札（表札）が付いている。囲みどうしは矢印でつながっている。3〜4 人がカードを動かしたり、札に書き込んだりしている
- **色**：囲みの線を緑、囲みどうしをつなぐ矢印をオレンジ（サイトの KJ 法の図と同じ）
- **代替テキスト（alt）**：壁に貼られたたくさんのカードを数人が囲み、似たカードを寄せて線で囲み、小さな札で名前を付けている様子の絵

### E2-02

**問いを交わすプレゼン**｜発想・設計会では｜16:9

- **伝えたいこと**：設計会の発表は一方通行ではなく、問いを交わして考えを深める場（「なんでもプレゼン」「小プレゼン」）
- **描くもの**：小さな教室。一人がスライドを指して話し、聞き手の何人かが手を挙げたり、メモを取ったり、隣と話したりしている。発表者と聞き手のあいだに、問いと答えを表す吹き出しが行き来している
- **注意**：堅い講義ではなく、和やかで対等な雰囲気
- **代替テキスト（alt）**：小さな教室で一人がスライドを指して発表し、聞き手の数人が手を挙げたりメモを取ったりしている様子の絵

### E3-01

**一脚の椅子の 4 つのモデル**｜モデル化のページ上部｜16:9

- **伝えたいこと**：同じものでも、目的によって違うモデル（表し方）を使う。モデルとは「何を残し、何を捨てるか」を決めたもの
- **描くもの**：同じ一脚の椅子を、左から右へ 4 通りに並べる。①手描きのラフスケッチ、②寸法の入った三面図、③立体のワイヤーフレーム（CAD 風）、④座面にかかる力を矢印で書き込んだ簡略図（棒と矢印だけ）。左ほど具体的、右ほど抽象的
- **色**：④の力の矢印をオレンジ、③のワイヤーフレームを青
- **代替テキスト（alt）**：一脚の椅子が、手描きのスケッチ、寸法の入った三面図、立体のワイヤーフレーム、力の矢印を書き込んだ図の四通りで横に並べて描かれた絵

### E3-02

**ライト兄弟の風洞**｜モデル化・いま｜16:9

- **伝えたいこと**：本物をつくる前に、模型（モデル）で何度も間違えることの価値。1901 年、ライト兄弟は自作の風洞で 200 種類ほどの翼の模型を試した
- **描くもの**：細長い木の箱の形をした風洞（片側に送風機）と、その中の天秤のような計測装置に取り付けられた小さな金属の翼の模型。手前の机には、形の違う翼の模型がいくつも並び、記録を書き込む手がある
- **注意**：当時の資料写真を参考にするのはよいが、写真を写さず、線画として描き起こす。細部の正確さより「小さく試す」雰囲気を
- **代替テキスト（alt）**：木の箱の形をした細長い風洞と、その中に並べられた小さな金属の翼の模型、手前に記録をつける人の手を描いた絵

### E4-01

**人の感覚と機器の手がかり**｜ヒューマンインターフェースのページ上部｜16:9

- **伝えたいこと**：インターフェースとは、人の感覚（見る・触れる・聞く）と、ものが出す手がかりが出会う境界面
- **描くもの**：一つの機器（ラジオや操作盤のような、つまみと小さな表示のあるもの。特定の製品にしない）を中心に、人の目・手・耳がそれぞれの手がかりに向き合っている。目と表示、手とつまみ、耳とスピーカーのあいだを点線で結ぶ
- **色**：点線を青、つまみなど「触れるところ」をオレンジ
- **代替テキスト（alt）**：人の手がつまみに触れ、目が表示を見て、耳がスピーカーからの音を聞いている様子を、一つの機器を囲むように描いた絵

### E4-02

**似た形のレバーと、形で区別できるつまみ**｜ヒューマンインターフェース・設計との関係／トップ・設計論 §06｜16:9

- **伝えたいこと**：第二次世界大戦中の爆撃機で、フラップと車輪の操作レバーがよく似た形で並んでいたため取り違えが起きた。先端に車輪の形とくさびの形を付けると、触っただけで区別できるようになった、という人間工学の有名な逸話
- **描くもの**：左右 2 コマの比較。左：操縦席の一部に、よく似た形の二本のレバーが並んでいる（「？」マークを添えてもよい）。右：同じ二本のレバーの先端が、一方は小さな車輪の形、もう一方はくさび（三角）の形になっている。右側に、手袋をはめた手がレバーを握っている
- **注意**：逸話の細部（レバーかスイッチか）は資料によって違うので、写実より「形で区別できる」というアイデアが伝わることを優先。軍用機の勇ましさは出さない
- **代替テキスト（alt）**：左側によく似た形の二本のレバーが並ぶ操縦席の一部、右側に先端が車輪の形とくさびの形になった二本のレバーを描いた比較の絵

### E5-01

**数字から立ち上がる形**｜データ分析のページ上部｜16:9

- **伝えたいこと**：数字の並び（表）が、見る人にとって意味のある形（グラフ）に変わる瞬間
- **描くもの**：画面の左側に、数字が並んだ表。それが右へ向かうにつれて、点・棒・扇形のグラフへと組み上がっていく。扇形は、ナイチンゲールの「鶏頭図」（扇形を重ねたグラフ）を思わせる形にすると、ページの内容とつながる
- **注意**：鶏頭図そのものを写さず、モチーフとして使う。数字は意味のない架空のものでよい
- **代替テキスト（alt）**：表に並んだたくさんの数字が、画面の奥に向かって扇形や棒の形のグラフへと組み上がっていく様子を描いた絵

### E5-02

**一つのノートブックを囲む**｜データ分析・設計会では｜16:9

- **伝えたいこと**：設計会では Deepnote（ブラウザで複数人が同時に編集できるデータ分析のノートブック）を使い、同じ数字を見ながら議論している
- **描くもの**：大きな画面に、コードの行・グラフ・説明の文章が縦に並んだ「ノートブック」が映っている。一人がグラフを指さし、二人がノートパソコンで同じ画面を編集している（画面の中に、それぞれのカーソルが色違いで見える）
- **注意**：Deepnote や Jupyter の**ロゴや実際の画面はそのまま描かない**。架空の、それらしい画面にする
- **代替テキスト（alt）**：大きな画面に映したデータ分析のノートブックを数人で見ながら、一人がグラフを指さし、ほかの人がノートパソコンで同じ画面を編集している様子の絵

### E6-01

**案を量る天秤**｜評価と意思決定のページ上部｜16:9

- **伝えたいこと**：設計の最後には、複数の案を物差し（評価基準）で比べて選ぶ瞬間がある
- **描くもの**：大きな天秤。左右の皿に、形の違う椅子の模型が一つずつ載っている。天秤の柱には「価格」「重さ」「美しさ」などの目盛り板が掛かっている。天秤はわずかに傾いている
- **色**：目盛り板を青、片方の模型をオレンジ
- **代替テキスト（alt）**：大きな天秤の両側に、形の違う椅子の模型が載り、天秤の柱に「価格」「重さ」「美しさ」と書かれた目盛り板が掛かっている絵

### E6-02

**投資家への大プレゼン**｜評価と意思決定・設計会では｜16:9

- **伝えたいこと**：設計会のプロジェクトの最後には、外部の方を含む「投資家」に設計解を発表し、なぜその案を選んだのかを問われる
- **描くもの**：発表者が、設計図と比較表（○△× や点数の表）を映したスクリーンの前に立っている。手前の机に、評価用紙を手にした数人の評価者が並び、一人が手を挙げて質問している
- **色**：スクリーンの比較表に青、発表者の手元の資料にオレンジ
- **注意**：張りつめすぎず、真剣で前向きな雰囲気
- **代替テキスト（alt）**：発表者が設計図と比較表を映したスクリーンの前に立ち、手前の机に並んだ数人の評価者が評価用紙を手に質問している様子の絵
